# 📦 Трекер импортных поставок

Простая система «под себя»: поставки → инвойсы → этапы процесса + документы в папках.
Для тебя и пары коллег. Всё хранится локально, бесплатно.

## Что умеет (версия 1)

- **Поставки** с номером. В поставке — несколько инвойсов (инвойс всегда в одной поставке).
- **Инвойс** = одно «дело» со своим процессом из 13 этапов:
  1. Инвойс → 2. Пакинг лист → 3. Перевод → 4. Камьен → 5. Спецификация →
  6. Русификация → 7. Отправлена на согл. (бренд-менеджер РУС) → 8. РУС согласовано →
  9. Файл товаров и паллет → 10. Склад → 11. Отправлено брокеру →
  12. Национальный каталог → 13. Транзит
- По каждому инвойсу сразу видно, **на каком этапе он сейчас**.
- У каждого этапа — статус (не начато / в работе / готово) и заметка (кому отправил, дата).
- **Файлы** можно прикреплять к конкретному этапу или в общую папку инвойса.
  Физически они лежат в папках на диске: `data/files/<поставка>/<инвойс>/`.
- Вход по логину, роли: администратор / сотрудник.

## Запуск на Windows (на «сервере-компьютере»)

Эту программу ставим на ОДИН компьютер — он будет сервером и хранилищем.
Коллеги к нему просто подключаются из браузера, у них ничего ставить не нужно.

1. **Один раз** установи Python 3.10+ с https://www.python.org/downloads/
   — при установке обязательно поставь галочку **«Add Python to PATH»**.
   (Если забыл галочку — переустанови и поставь её.)
2. Дважды кликни по файлу **`start.bat`**.
   Первый запуск настроит всё сам (минутку), дальше — запускается быстро.
3. В открывшемся чёрном окне будет написано два адреса, например:
   ```
   На ЭТОМ компьютере:   http://127.0.0.1:8000
   Коллегам в сети дать: http://192.168.1.50:8000
   ```
4. Открой первый адрес в браузере. Первый вход: **admin / admin**.
5. Чтобы остановить сервер — просто закрой чёрное окно.

> Если Python ещё не установлен, `start.bat` сам подскажет ссылку и что сделать.

## Доступ для коллег (офисная сеть)

1. Пока `start.bat` запущен на сервере-компьютере — дай коллегам **второй адрес**
   из окна (вида `http://192.168.1.50:8000`). Они открывают его в своём браузере
   (Chrome/Edge) и видят те же поставки и файлы.
2. В разделе **«Пользователи»** (виден администратору) заведи каждому логин и пароль.
3. Компьютер-сервер должен быть включён, пока коллеги работают.

> Коллеги не видят адрес / «страница не открывается»? Обычно мешает брандмауэр
> Windows на сервере — при первом запуске разреши Python доступ к сети
> (всплывёт окно), либо открой порт 8000 для частной сети.

## Смена пароля администратора

По умолчанию admin / admin. Либо задай свой пароль до первого запуска
(переменная окружения `ADMIN_PASSWORD`), либо заведи себе личного пользователя
в разделе «Пользователи» и работай под ним.

## Где что лежит

| Файл/папка | Что это |
|---|---|
| `app.py` | Веб-приложение (маршруты, загрузка файлов, вход) |
| `db.py` | База данных SQLite + **список этапов** (`DEFAULT_STEPS`) |
| `templates/` | Страницы (HTML) |
| `data/tracker.db` | Сама база (создаётся при первом запуске) |
| `data/files/…` | Загруженные документы в папках по поставке/инвойсу |

## Как поменять список этапов под себя

Открой `db.py`, найди `DEFAULT_STEPS` и измени список. Новые инвойсы будут
создаваться уже с новыми этапами. (Старые инвойсы сохраняют свой список —
менять этапы у уже созданных инвойсов добавим в следующей версии.)

## Резервная копия

Просто скопируй папку `data/` — там и база, и все документы.
